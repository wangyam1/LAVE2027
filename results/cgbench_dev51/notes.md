# LAVE 熵控多区间缺失事实路由（`entropy_routing_20261125`）

## 改进动机（针对 `missing_fact_routing_20261124` 暴露的 3 个硬瓶颈）
1. **去掉未校准的 `margin > 0` 先验硬截断**：Qwen3.5 无图基线强偏 `N`（约 −3.0 log-odds），导致 44 个可扫描视频中 30 个（68%）虽有正置零增益（中位 +2.625）却未进入对照。改为校准 lift（`lift > 0`）提名，仍须严格通过全部三项内容对照（同视频半圈错位 `shifted`、通道扰乱 `scrambled`、错目标 `wrong_target`）。
2. **引入论文 Introduction 的熵控多区间预算分配**：固定总预算 32 帧（16 锚点 + 16 增量帧），按合法区间 lift softmax 的教科书归一化香农熵三分位（`< 1/3 → K=1`、`[1/3, 2/3) → K=2`、`≥ 2/3 → K=4`）选取 `K` 个非相邻峰值区间（NMS，`|a-b|>1`），每区间等分 `16/K` 帧；时钟对照使用完全相同 `K`、相同每区间帧数与 NMS 规则的贪心最远点新颖性选择（`clock_split`）。
3. **放宽多帧引用上限**：针对上一轮 `refocus`（15/15）与 `focus_side`（13/20）因引用 >2 帧被丢弃的问题，将定向报告合法引用放宽至 1–8 个不重复整数帧号并允许 1–2 句事实描述；同时保留 100% 未修改的原生 `native` 报告做 3×2 因子配对对照。

## 协议冻结前两项核验（51 开发视频内，未触碰 96 确认集）

### 1. 五个胜例的原始实拍帧视觉复核
导出全部 5 个 `on_policy` 胜例的实际 Focus-1/Focus-2 JPEG 拼图并逐帧目视核对（[win_audit_sheets](win_audit_sheets)）：
- **`case_06`（悬空石，独赢 text 与 clock）**：**确认为严格的 LAVE 独有新帧因果胜例**。Focus-1 从状态新窗定位至 `215.5s/241.4s`，Focus-2 在 `F2[6] 223.9s` 清晰拍到绿色垃圾车撞碎悬空石且路上无自行车，直接支持选项 A（`text` 与 `clock_split` 均无有效画面）。
- **`case_16`（金豪 80 钢笔价格，独赢 text 与 clock）**：**确认为严格的 LAVE 独有新帧因果胜例**。Focus-1 从状态新窗锚定 `284.2s/303.8s`，Focus-2 在 `F2[7] 292.7s` 清晰拍到正中字幕「金豪的80大概20多块钱」，使纯文字 QA 由错翻对（`text` 与 `clock_split` 均返回空观察）。
- **`case_20`（潜水员海洋生物，独赢 text 与 clock）**：画面真实显示珊瑚礁小鱼与潜水员，但 `text` 在 Focus-2 也进入了相近 `1204s–1250s` 区间；胜出来自同区间的更聚焦报告表述，不记作 LAVE 独有新帧发现。
- **`case_38`（小狗颜色，on-policy 独赢 / equal-budget 持平）**：`F1[17] 1927.5s`、`F1[19] 1940.6s` 真实可见黑色小狗，但均属与文字共享的锚点帧（`ANC`），`equal_budget` 补拍后两对照也追平。
- **`case_41`（炅炅与白白，赢 text / 平 clock）**：关键帧 `478.2s` 为与 `clock_split` 共享的锚点帧。
- **结论**：5 例中 **2 例为无可争议的 LAVE 独有新帧因果胜例**，3 例为共享区域/锚点上下文正向翻转，**0 例幻觉或捷径**。
